# 🔐 What is Cyber Security?

Cyber Security is the practice of protecting:

- 💻 Computers
- 🌐 Networks
- 📱 Applications
- 📂 Data

from unauthorized access, attacks, damage, or theft.

### 🕵️ Hacking

Hacking is the process of finding weaknesses in systems and using them to gain access.

### ✅ Ethical Hacking

Ethical hacking is authorized hacking performed to identify and fix security vulnerabilities.


---

# 🕵️ Types of Hackers

Hackers can be classified in different ways.

## Based on Ethics

### ⚪ White Hat Hackers
- Authorized security professionals.
- Find and fix vulnerabilities.

### ⚫ Black Hat Hackers
- Malicious attackers.
- Exploit systems for personal gain.

### ⚪ Gray Hat Hackers
- Between white and black hats.
- May find vulnerabilities without permission.


## Based on Skill

### 🟢 Newbie / Noob
- Beginners with little or no hacking knowledge.
- Mostly learning basic concepts and security fundamentals.

### 🟡 Script Kiddies
- Beginners who use existing hacking tools and scripts.
- Often do not fully understand how the tools work.

### 🟠 Hacker
- Skilled individuals who understand systems, networks, and security.
- Can create their own techniques and tools.

### 🔴 Elite Hackers
- Highly skilled experts with advanced knowledge.
- Discover complex vulnerabilities and develop advanced security techniques.

# ❓ Why Learn Cyber Security?

Cyber security is important because:

- 🛡️ Protects personal and business data.
- 🌐 Secures online services.
- 💰 Prevents financial loss.
- 🚨 Detects and responds to attacks.
- 👨‍💻 Creates career opportunities.

Anyone who has:

- ⚖️ Strong ethical responsibility.

# 🔑 Elements of Information Security

The foundation of security is the **CIA Triad**.

## 🔒 Confidentiality

Ensures information is only accessible to authorized users.

Example:
- Password protection
- Encryption


## 📝 Integrity

Ensures data remains accurate and unchanged.

Example:
- File checksums
- Digital signatures


## ⚡ Availability

Ensures systems and data are available when needed.

Example:
- Backup systems
- Disaster recovery

# 🚀 Phases of Hacking

Ethical hacking follows these phases:

1. 🔎 **Reconnaissance**
   - Gathering information about the target.

2. 📝 **Scanning**
   - Finding open ports and vulnerabilities.

3. 🚪 **Gaining Access**
   - Exploiting discovered weaknesses.

4. 🔥 **Maintaining Access**
   - Testing persistence.

5. 🧹 **Covering Tracks**
   - Understanding attacker techniques.


---

# 🎯 Penetration Testing

Penetration Testing is an authorized security test that simulates real attacks to identify vulnerabilities.

Purpose:

- Find security weaknesses.
- Improve defenses.
- Prevent real attacks.


---

# 🧪 Types of Penetration Testing

## 🌐 Black Box Testing
- Tester has no prior knowledge of the system.

## ⚪ White Box Testing
- Tester has complete system information.

## 🔘 Gray Box Testing
- Tester has partial information.


---

# 📖 Cyber Security Field Terms

## 🔴 Red Teaming / Offensive Security

Red Teaming simulates real-world attacks to test an organization's security.

Focus:
- Finding weaknesses.
- Testing attack methods.


## 🔵 Blue Teaming / Defensive Security

Blue Team protects systems from attacks.

Responsibilities:

- Monitoring systems.
- Analyzing network traffic.
- Responding to threats.
- Improving security controls.


## 📋 Security Audit

A Security Audit evaluates:

- Security policies.
- Systems.
- Procedures.
- Compliance requirements.


## 🔍 Vulnerability Assessment

A Vulnerability Assessment identifies security weaknesses using:

- Automated scanning.
- Manual testing.
- Security analysis.

# ⚖️ Ethics of Cyber Security

Ethical hackers must:

✅ Get permission before testing.  
✅ Protect confidential information.  
✅ Report vulnerabilities responsibly.  
✅ Use skills for legal purposes.  
✅ Respect privacy.
